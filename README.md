# Residencial Vida Serena

Site institucional desenvolvido com **HTML, CSS e JavaScript**, representando um residencial voltado ao cuidado e bem-estar da terceira idade.

O projeto foi criado como exercício de **desenvolvimento web front-end**, com foco em layout moderno, responsividade e boas práticas de estrutura de código.

---

## 📷 Visão geral

O site apresenta:

* Banner institucional
* Seção "Quem Somos"
* Estrutura do residencial
* Serviços oferecidos
* Formulário de contato
* Botão de contato via WhatsApp
* Layout responsivo para dispositivos móveis

---

## 🚀 Tecnologias utilizadas

Este projeto foi desenvolvido utilizando:

* **HTML5** – Estrutura da página
* **CSS3** – Estilização e layout
* **JavaScript** – Interatividade e animações
* **Google Fonts** – Tipografia moderna

## ✨ Funcionalidades

### Menu responsivo

O menu de navegação se adapta para dispositivos móveis com botão **hamburger**.

### Animação ao rolar a página

Os cards da seção de estrutura aparecem com animação quando entram na área visível da tela.

### Botão de WhatsApp

Um botão flutuante permite iniciar rapidamente uma conversa.

### Layout responsivo

O site funciona corretamente em:

* Desktop
* Tablet
* Smartphones

---

## 📱 Responsividade

O layout utiliza **Flexbox e Grid** para garantir adaptação a diferentes tamanhos de tela.

Breakpoints principais:

```
900px
768px
```
